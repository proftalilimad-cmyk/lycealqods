# تحويل ملفات التلاميذ إلى PDF دفعة واحدة

الموقع ثابت (بلا خادم)، لذلك أزرار **PDF** داخل الموقع تفتح نافذة الطباعة باسم الملف
جاهزًا — تختار «حفظ بصيغة PDF» فيُنزَّل بالاسم المطلوب:

```
محمد_العربي_001_التقويم_التشخيصي.pdf
```

أما إذا أردت **كل ملفات القسم PDF دفعة واحدة** (بلا نقر على كل تلميذ)، فاستعمل
الأداة المحلية `scripts/html-to-pdf.mjs` على حاسوبك. هي تُكمل ما نزّلته من الموقع:
تأخذ الأرشيف ZIP (أو المجلد) وحوّل كل وثيقة تلميذ إلى PDF **بالاسم نفسه وفي المجلد
نفسه**، ثم تعيد أرشفة الكل إن طلبت ذلك.

```
الجذع_المشترك/جذع_مشترك_علوم_خ_ف_1/001_محمد_العربي.html
                                  ↓
الجذع_المشترك/جذع_مشترك_علوم_خ_ف_1/001_محمد_العربي.pdf
```

## الخطوات

### 1) نزّل الأرشيف من الموقع

`لوحة الأستاذ` ← `نتائج التقويم التشخيصي` ← اختر القسم (و/أو حدّد تلاميذ) ←
**«تحميل أجوبة التلاميذ ZIP»** أو **«تحميل جميع نتائج القسم»**.

### 2) التهيئة (مرة واحدة)

يلزم Node.js (18 أو أحدث)، ثم:

```bash
npm i -D playwright
npx playwright install chromium
```

> عندك Chrome أو Edge مثبّت؟ يمكنك الاستغناء عن التنزيل:
> `--channel chrome` أو `--channel msedge`.

### 3) التحويل

```bash
# أرشيف كامل ← مجلد PDF (+ أرشيف نهائي مع --zip)
node scripts/html-to-pdf.mjs ~/Downloads/التقويم_التشخيصي_جذع_مشترك_علوم_خ_ف_1.zip --zip

# أو عبر npm
npm run pdf:batch -- ~/Downloads/التقويم_التشخيصي_جذع_مشترك_علوم_خ_ف_1.zip --zip

# مجلد بدل أرشيف
node scripts/html-to-pdf.mjs ./ملفات-القسم --out ./pdf

# تجربة بلا تحويل (لا تحتاج متصفحًا): تعرض الخطة والأسماء
node scripts/html-to-pdf.mjs ./ملفات-القسم --dry-run
```

## الخيارات

| الخيار | المعنى |
| --- | --- |
| `--out <مجلد>` | مجلد الإخراج (افتراضيًا `<المدخل>-pdf` بجانبه) |
| `--zip` | إنشاء أرشيف ZIP من النتيجة النهائية |
| `--keep-html` | الإبقاء على نسخ HTML بجانب PDF |
| `--concurrency <n>` | عدد التحويلات المتوازية (افتراضيًا 3) |
| `--channel <chrome\|msedge>` | استعمال متصفح مثبّت بدل Chromium المنزّل |
| `--executable-path <مسار>` | مسار متصفح محدّد |
| `--dry-run` | عرض ما سيُنفَّذ دون تحويل |

## ماذا يوجد في الإخراج؟

- لكل تلميذ(ة): `NNN_الاسم.pdf` — الملف الفردي الكامل (الغلاف + كل الأسئلة
  وإجابات التلميذ والجواب الصحيح ونقطة كل سؤال + النتيجة النهائية + تحليل
  مواطن القوة والضعف + توصيات الدعم التربوي).
- `تقرير_شامل_*.pdf` — تقرير القسم.
- بقية ملفات الأرشيف تُنسخ كما هي: `جدول_النتائج_*.xlsx`، نسخ Word `*.doc`، و`اقرأني.txt`.
- المقاس A4 بهوامش 14/12 مم، مع الألوان والخلفيات، والاتجاه من اليمين إلى اليسار.

## ملاحظات وحلول

- **الأسماء العربية:** الأرشيف يُفكّ بقارئ ZIP مكتوب داخل الأداة (UTF-8)، فلا يتوقف
  على `unzip` النظام الذي يُعطّب الأسماء العربية أحيانًا.
- **بلا أنترنت:** الوثائق تستعمل خطوط النظام العربية إن تعذّر تحميل خطوط جوجل؛
  الشكل يبقى سليمًا وقد يختلف نوع الخط قليلًا.
- **ويندوز:** الأداة تعمل في PowerShell وCMD. لإنشاء الأرشيف النهائي (`--zip`)
  يلزم أمر `zip` (متوفر في Git Bash) وإلا اكتفت الأداة بالمجلد الناتج.
- **عدد كبير من التلاميذ:** التحويل متوازٍ (3 افتراضيًا). لأرشيف 40 تلميذًا
  انتظر نحو دقيقة على حاسوب عادي.
- **لا حاجة لهذه الأداة** إن كنت تريد ملف تلميذ واحد: زر «أجوبة PDF» في الموقع يكفي.
